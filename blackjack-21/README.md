# 21 点 · Blackjack（多人扑克）

起始筹码可配置（**统一额度 / 随机分配 / 逐人调配**，每人最低 1000）。掷骰定庄、下注、逐张发牌的经典 21 点，支持 **2~5 人**、每个座位自由选择**真人 / 🤖 电脑**（全员电脑即观战模式）。

## 规则

1. **掷骰定庄**：发牌前掷一颗骰子（1~6 点），从 P1 数起对应座位为本局庄家；庄家破产则顺延
2. **起始筹码**：设置页可选统一额度（自定义数值）、随机分配（1000~10000，可重新随机）或逐人调配，每人最低 1000；重置筹码按此配置恢复
3. **下注**：闲家各下底注（10 ~ 全部筹码），电脑自动下 100；Blackjack 赢 **1.5 倍**、小老虎赢 **2 倍**、普通胜 **1 倍**、输扣底注
3. **逐张发牌**：从庄家座位开始，一人一张轮流发，两轮后每人两张；**所有手牌背面朝上**
4. **要牌 / 停牌**：从庄家下家开始行动——
   - **只有轮到的本人能看到自己的牌**（多人真机时先弹"传递设备"确认层），打完扣回
   - 别人的要牌/停牌/爆牌只播报动作，不看牌面与点数；**庄家亮牌时才公开**，结算全部摊牌
   - 超过 21 点即爆牌出局；两张恰 21 点为 **Blackjack**；**凑满 5 张且 ≤18 点为 🐯 小老虎**
   - **真人当庄也手动决定**要牌/停牌（电脑庄家 17 点起停）
5. **结算**：牌型排序 爆牌 < 点数 < Blackjack < 小老虎；庄家爆牌则未爆玩家全胜；同为小老虎庄家胜；点数相同平局退注

## 操作

| 操作 | 说明 |
| --- | --- |
| 要牌 / 停牌 | 按钮，或快捷键 **H** / **S** |
| 音效开关 | 顶部按钮或 **M** |

- 筹码耗尽（<10）的座位自动旁观；**只剩一人有筹码时直接夺得最终胜利**（🏆 结算横幅，可一键"再战一场"重置筹码）
- **下注阶段可中途加入新玩家**：输入名字选真人/电脑即可入座（自带 1000 筹码，上限 5 座；没人来也随时开牌）
- "下一局"重新掷骰定庄，筹码与胜场跨局累计

## 技术

纯原生 HTML + CSS + JavaScript；发牌、骰子、胜负均为动画呈现，音效为 Web Audio 程序化合成，零外部依赖。

## 本地运行

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080/blackjack-21/
```
