📋 使用说明

  1. 从模拟器(e.g. RetroArch / Snes9x / VBA)导出存档为 .srm / .sav,部分版本可能命名为 .ffd。
  2. 选择对应游戏版本(模板定义了属性在存档中的字节偏移)。
  3. 编辑左侧数值,中间区域实时显示新属性。
  4. 点击"导出修改后存档"保存为新文件,放回模拟器覆盖即可生效。

使用说明 / 注意事项

关于 FFD 格式

FFD 在不同社区有不同含义:Final Fantasy Dawn、Final Fantasy Data 或仅为模拟器自定义扩展名。本工具支持 .ffd / .sav / .srm / .bin / .dat 等任意扩展名,核心按字节解析。

关于存档版本

同一作不同平台(NES / SNES / GBA / NDS / PSP) 存档结构差异极大,请务必选择正确的"游戏 + 平台"组合,否则读出的属性会错位。

关于备份

导出文件会保留原扩展名,默认下载为 原文件名.modified.ffd。建议覆盖前先备份原存档。

安全提示

所有解析与编辑均在本地浏览器执行,文件不会上传到任何服务器。
