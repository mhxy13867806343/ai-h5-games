# 峡谷对决 · Rift Duel —— LoL 对局流程复刻

复刻《英雄联盟》官网对局的完整流程：**英雄选择 → 战场加载 → 中路 1v1 打斗 → 胜利 / 失败结算**。玩法为示意性复刻，重在流程体验。

## 英雄数据

实时来自 lol.qq.com / game.gtimg.cn 公开接口（均已开放 CORS）：

| 数据 | 接口 |
| --- | --- |
| 英雄列表（173 位） | `game.gtimg.cn/images/lol/act/img/js/heroList/hero_list.js` |
| 英雄详情（属性/技能/原画） | `game.gtimg.cn/images/lol/act/img/js/hero/{heroId}.js` |
| 头像 / 技能图标 | `…/champion/{Alias}.png`、`…/spell/{Alias}{Q|W|E|R}.png` |

- 选择界面：173 位英雄实时拉取，支持搜索与定位筛选（战士/坦克/法师/刺客/射手/辅助）
- 加载界面：真实属性（HP/攻击/护甲/移速/射程）、真实技能名称与图标、原画
- 接口不可达时自动回退到内置精简数据（`hero-fallback.js`），游戏仍可玩

## 玩法

| 操作 | 键盘 | 鼠标 |
| --- | --- | --- |
| 移动 | W A S D / 方向键 | 点击地面 |
| Q / R（方向技能） | Q / R，朝鼠标方向释放 | 点技能按钮 |
| W（治疗+加速） | W | — |
| E（向鼠标突进） | E | — |
| 暂停 | P / Esc | — |
| 音效开关 | M | 顶部 🔊 按钮 |

音效为 Web Audio 程序化合成（零外部文件）：选人、锁定、普攻、Q/W/E/R、防御塔、补刀金币、击杀、胜利/失败各有专属音效，偏好自动记忆。

- 站在**己方防御塔**范围内快速回血回蓝；进入**敌方防御塔**范围会被塔攻击
- 每波小兵从两方防御塔出发沿中路推进，普攻范围自动交战；补刀得金币
- 击败对方英雄获胜，被击败则失败；结算面板显示用时 / KDA / 补刀 / 金币 / 对英雄伤害

## 技术

纯原生 HTML + CSS + JavaScript（Canvas 2D），无任何框架与构建步骤。

## 本地运行

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080/lol-rift-duel/
```
