# LPL ARENA · 英雄联盟职业联赛赛事数据中心

复刻 [lpl.qq.com](https://lpl.qq.com/) 的多页面赛事数据展示：**首页 / 赛程 / 积分榜 / 战队 / 战队详情**，点击导航切换页面展示不同数据。

## 数据来源

| 数据 | 来源 | 加载方式 |
| --- | --- | --- |
| 战队列表（队标/名称） | `lpl.qq.com/web201612/data/LOL_MATCH2_TEAM_LIST.js` | `<script>` 标签**实时加载**（官方接口，GBK 编码） |
| 首页轮播 | `…/LOL_NEWMATCH_FIR_PAGE_RECO_INFO.js` | 实时加载 |
| 各赛季赛程比分 | `…/LOL_MATCH2_MATCH_HOMEPAGE_BMATCH_LIST_{seasonId}.js` | 官方该接口为纯 JSON 且跨域受限，采用**本地爬取快照**（`js/data-snapshot.js`，2026-10-24 抓取） |
| 积分榜 | 由赛果数据实时计算（胜负 / 小局 / 净胜局 / 胜率） | 本地计算 |

- 快照覆盖赛季：2026 职业联赛（249 场）、2026 全球总决赛（46 场）、2026 季中冠军赛（20 场）、2025 职业联赛（459 场）、2025 全球总决赛（41 场），共 815 场
- 实时接口不可达时自动回退快照数据，页面可完整浏览

## 页面

- **首页**：官方轮播图（自动播放）、最新赛果、2026 LPL 第三赛段积分速览、LPL 战队横排
- **赛程**：赛季切换 + 轮次/日期分组 + 战队搜索，比分与状态一目了然
- **积分榜**：赛季 + 阶段（组内赛/淘汰赛/骑士之路…）切换，排名、小局、胜率条
- **战队**：全部参赛战队卡片，点击进入战队详情
- **战队详情**：队标信息、快照内各赛季战绩统计、总胜率、最近比赛

## 技术

纯原生 HTML + CSS + JavaScript，零依赖；跨域数据用 `<script>` 标签加载（与官网同款方案）。

## 本地运行

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080/lpl-arena/
```
