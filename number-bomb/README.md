# 数字炸弹 · Number Bomb

0 到 N 之间藏着一颗“炸弹”数字，玩家轮流报数收紧范围：

- 报的数**小于炸弹** → 它成为新的下界（如报 50，范围变为 50 ~ N）
- 报的数**大于炸弹** → 它成为新的上界
- **直接报中炸弹数字** → 立即引爆，报数者输
- 范围收到**只剩炸弹一个数**可报（如目标 10，有人报 9、另一人报 11）→ 下一个人不用再报，直接判负

## 模式与设置

- **人数**：2~5 人，每个座位可单独勾选“🤖 电脑”或真人（如 1、2 号真人 + 3、4、5 号电脑）
- **全员电脑** = 观战模式，游戏自动对局演示
- **电脑策略**：区间中位拆分 + 扰动，不偷看炸弹
- **范围**：0~1000 / 0~10000 / 自定义 N（10 ~ 999999）
- 每次报数后播报：如“玩家 1 输入了 23 → 范围变为 23 到 100”

## 操作

- 轮到真人时在输入框报数（必须是当前开区间内的整数），回车或点“报数！”
- 电脑回合自动进行，实时显示当前范围、剩余可报数量、座位高亮、轮次与完整报数记录
- 音效开关：顶部按钮或 **M** 键；踩雷爆炸有爆炸音效与画面震动

## 技术

纯原生 HTML + CSS + JavaScript，音效为 Web Audio 程序化合成，零外部文件、零依赖。

## 本地运行

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080/number-bomb/
```
