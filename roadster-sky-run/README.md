# Roadster · 飞跃收费站 — 四车道随机追击版

以提供的 Roadster 游戏截图为参考重新实现的 H5 驾驶小游戏。银色冷气跑车自动沿四车道高速行驶，玩家需要穿过随机生成的地面车流、飞越有收费员的收费站，并在过站后的空中躲避路侧炮台的炮弹。

## 本次新增

- 每局随机车流：开始、失败重开和暂停后重新出发都会生成新车流。车辆的车道、间距、车型、配色和巡航速度会变化；暂停再继续保留当前局。初始生成6–8辆车，后续车辆也随机补充，并保留安全起步距离及同车道间隔。
- 四车道高速：道路、分道线、护栏、转向范围和交通车辆共用四车道坐标。收费站同步扩为四个通道、四个收费亭和四组栏杆。
- 收费员：每个收费亭窗口都有戴帽子、穿制服的人形收费员，窗口使用可看见人物的结构，车辆接近时可看到挥手动作。
- 过站后炮台追击：炮台放在每座收费站后方85米的路侧。玩家整辆车越过收费站后，炮台才会锁定空中目标，预警约1.15秒后开火；炮管转向、警示灯、炮口闪光和炮弹均在场景中表现。发射后的炮弹沿既定弹道前进，可以横向变向或下降躲避；中弹会结算本局。
- 战斗提示：HUD 显示前方车辆、超车计数、锁定进度和炮弹来袭提示；锁定、开火有可开关的提示音。
- 保留飞越收费站、冷气补充、最高分、键盘/触屏操作和暂停重开的完整循环。追击模式的最高分单独保存。

## 直接试玩

打开 `dist/index.html` 即可开始。该文件已经包含 Vue、Vant、Three.js、场景与游戏逻辑，不需要安装依赖、登录或请求外部素材。可以直接在支持 WebGL 的现代浏览器打开，也可以把 `dist` 上传至静态网站托管服务。手机可使用屏幕下方触摸按钮。

`dist/preview-fragment.html` 是同一游戏的嵌入式预览片段；完整网页请使用 `dist/index.html`。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 开始 | 点击“开始驾驶” | 点“开始驾驶” |
| 向左 / 向右 | A / D 或左右方向键 | 按住左 / 右按钮 |
| 喷气起飞 | 按住空格键，松开下降 | 按住“冷气”按钮，松开下降 |
| 减速 | S 或下方向键 | 按住“减速” |
| 暂停 / 继续 | P / Esc 或暂停按钮 | 暂停按钮 |
| 失败后重开 | R 或“再跑一次” | “再跑一次” |
| 声音开关 | M 或音符按钮 | 音符按钮 |

收费站距离约 **75 米** 时按住冷气起飞，收到“成功飞越”后再松开。第一次尝试可在 65–90 米范围内起跳，但新模式还需要避让车辆与炮弹。冷气消耗完会停止喷射，需要先松开，再等落地自动补充。

飞越收费站后，留意前方路侧的炮台。看到“炮台正在锁定”时准备左右变向；“炮弹来袭”出现后改变横向位置。继续保持高飞直行会受到追击，越站后也可以松开冷气下降。炮台只锁定高度超过2.8米的目标，降到低空会解除未完成的锁定，已经发射的炮弹仍会继续飞行。

得分为整数行驶米数，加每座收费站的 500 分奖励，以及每辆完整超越车辆的 100 分奖励。只有整辆车越过棚体或前车才计分；高度不够或提前下降碰到棚顶会结束本次驾驶。左右路肩设有软限制。后续收费站逐渐加高、加深，游戏可连续进行。

离开页面、切换标签页或窗口失焦时会暂停，避免未操作时继续撞站。最高分仅保存在当前浏览器；若嵌入预览不允许本地存储，则本次会话内仍保留最高分。音效默认关闭，需要点击开关后启用。

## 开发

环境：Node.js 20.19+，建议使用 Node.js 22 或 24。

```bash
npm install
npm run build
npm test
```

依赖固定为 Vue 3.5.44、Vant 4.10.2、esbuild 0.28.2。Three.js r149 的分发文件已保存在 `vendor/three.min.js`。界面使用 Vue 3 与 Vant Button，3D 场景使用 Three.js；所有车辆、道路、收费站、山脉、树木和纹理均由本项目代码生成。

## 文件结构

- `src/main.mjs`：Vue / Vant 界面、HUD、触摸按钮、开始与结算界面。
- `src/runtime.mjs`：动画循环、键盘/指针输入、暂停恢复、最高分、声音接入。
- `src/simulation.mjs`：独立模拟引擎；以米和秒为单位，负责飞行、燃料、收费站与碰撞。
- `src/hazards.mjs`：地面车辆、炮塔锁定、炮弹、命中与超车统计。
- `src/road-config.mjs`：四车道中心、道路宽度、起步车道、转向范围和炮台侧向位置的共享常量。
- `src/scene.mjs`：Three.js 场景、追车镜头、车辆与公路、喷气及落地效果。
- `src/hazard-scene.mjs`：轿车/SUV/货车模型、追踪炮塔、锁定线圈与炮弹尾迹，复用固定对象池。
- `src/audio.mjs`：用户手势解锁的本地 WebAudio 音效。
- `src/ui.css`：手机与桌面界面样式。
- `scripts/build.mjs`：生成完整单文件网页和内嵌预览。
- `tests/`：模拟与输入生命周期的功能测试。
- `THIRD-PARTY-LICENSES.txt`：所包含第三方依赖的许可证。

## 验证范围

47项自动化功能测试通过，覆盖基础飞行和收费站碰撞、每局随机车流及固定种子复现、四车道与安全起步、地面车辆前进/碰撞/超越、越站前不锁定与越站后实际开炮、命中与变向躲避、发射后弹道固定、敌人数量上限、暂停冻结、重开清空、HUD 威胁同步、最高分、输入生命周期与 WebGL 中断恢复。同帧飞越与锁定也验证了警报提示和音效各触发一次。

真实车流和炮台均开启的固定种子局面，包含连续通过3座收费站的自动回归。随机生成安全性另用120个种子检查；这不等于所有随机局都已进行完整通关。基础飞行的30/60/120 FPS长跑校准单独关闭危险机制，以便隔离飞行本身的稳定性。

正常游戏不固定随机种子。开发时可用 `createGame({ seed: 123 })` 复现某一局；该显式模式下重开也复现同一车流，用于测试和排查。随机数仅在生成车辆时消耗，每辆车保留自己的巡航速度。

Three.js 几何及相机矩阵检查覆盖320至1280像素的54组尺寸、高度及横向位置，以及84帧最大转向运动。检查了四条车道、四个收费通道、四名收费员，并确认刚过站时前方约79米处的左右炮台处于窄屏相机视野；车型尺寸、炮管朝向、炮弹尾迹、暂停及资源释放也通过检查。Vue/Vant界面和实际场景图通过了替代GPU接口的DOM联动检查。实际WebGL像素表现、手机GPU性能和声音听感尚未进行真实浏览器验收。

这是基于截图制作的独立可玩版本，未获取原站源码，不代表原游戏的完整规则或资产。
